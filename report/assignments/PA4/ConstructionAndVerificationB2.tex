\section{Security, Database, Accessibility and Operations Hardening}
Ahead of the B2 candidate tag, a comprehensive multi-layer audit and remediation pass delivered:
\begin{itemize}
  \item \textbf{Database \& Concurrency (\texttt{1795600000000}):} Changed overflow and combined-minimum FKs to
        \texttt{ON DELETE RESTRICT}, guarded non-default GPA/credit flags on unlink, serialized \texttt{AccountService.requestDeletion}
        with \texttt{ADMIN\_WRITE\_LOCK} to preserve \texttt{last\_access\_manager}, and added five missing lookup indexes.
  \item \textbf{Security \& AI Gateway:} Added strict \texttt{Content-Security-Policy} (SHA-256 pinned boot script), HSTS and
        Express security headers; rejected unsafe \texttt{TRUST\_PROXY=true}; released AI daily quota on unbilled connection and
        \texttt{400/404} errors; and wired SSE client disconnects to abort upstream OpenRouter streams.
  \item \textbf{Frontend \& WCAG 2.1 AA:} Converted all 20+ routes to lazy dynamic imports (reducing max JS chunk from
        537.8 kB to 77.8 kB), scoped every view SFC stylesheet (enforced by \texttt{npm run lint}), fixed WCAG AA light/dark
        contrast ratios, and eliminated W3C combobox accessible-name pollution.
  \item \textbf{Disaster Recovery \& Rollback:} Configured HTTP \texttt{503} on degraded \texttt{GET /api/health} paired with
        \texttt{omnicourse-deploy} automatic symlink rollback, plus \texttt{omnicourse-backup.timer} for 14-day nightly dumps.
\end{itemize}
