## Fast Build Commands

```powershell
# In PowerShell:
./build.ps1 -Target weekly          # Build all weekly reports
./build.ps1 -Target week3           # Build only Week 3
```

```bash
# In Bash:
./build.sh weekly                   # Build all weekly reports
./build.sh week3                    # Build only Week 3
```
