```js
const realFetch = window.fetch.bind(window);
window.fetch = (url, init = {}) => {
```

### TC-B2-ADM-05: Validation, atomicity and impact

```js
const realFetch = window.fetch;
window.fetch = async (input, init = {}) => {
  if ((init.method ?? 'GET').toUpperCase() === 'GET') return realFetch(input, init);
  window.fetch = realFetch;
  await realFetch(input, init);
  throw new TypeError('ADM-05f: answer dropped by the test');
};
```

### TC-B2-ADM-07: CSV bulk import

A synthetic CSV of courses or group links is parsed deterministically and shown as a preview with errors by row number. A file with any bad row saves nothing, a valid file saves in one transaction after confirmation with the same permission checks as manual entry, and importing it again creates no duplicates ([test plan row](test-plan.md#b2-checks)).

- Owner: Thắng
- Depends on: the CSV import API of [#147](https://github.com/LLaammTTeerr/omnicourses/pull/147) ([ADR 0011, CSV import as built](../analysis-and-design/adr/0011-curriculum-administration.md#csv-import-as-built-25-november-2026)); ADR 0011 (accepted). These cases call the API only: no screen calls the import yet ([#151](https://github.com/LLaammTTeerr/omnicourses/issues/151)). #147 merged into `main` on 25 November 2026 (`2363714`).
- Group totals stay **blocked** (ADM-07k). Lâm decided on 25 November 2026 that the group-link import ships with the structural checks of the manual route and no group-total check ([ADR 0011, amendment of 25 November](../analysis-and-design/adr/0011-curriculum-administration.md#amendment-25-november-2026-csv-group-links-with-structural-checks-only): "The group-total part of TC-B2-ADM-07 stays blocked"). ADM-07a–j check everything else, so Triết's handoff no longer blocks them.

**How an import works.** Four `POST` routes, each answering **200** on success, under `curriculum-admin` in Swagger:

| Route | Grant | Body |
| --- | --- | --- |
| `/api/admin/catalog/imports/preview` | `catalog_maintainer` | `{ "csv": "…" }` |
| `/api/admin/catalog/imports/confirm` | `catalog_maintainer` | `{ "csv": "…", "reviewVersion": "…" }` |
| `/api/admin/programs/{programId}/cohorts/{curriculumId}/imports/preview` | the program's `program_admin` | `{ "csv": "…" }` |
| `/api/admin/programs/{programId}/cohorts/{curriculumId}/imports/confirm` | the program's `program_admin` | `{ "csv": "…", "reviewVersion": "…" }` |

The file travels as a JSON string: no upload, and the server keeps no file. A preview saves nothing and answers the normalized rows (`action` `insert`, `update` or `no_op`), the row `errors` (`record`, `field`, `message`, where the header is record 1), a `summary` (`inserts`, `updates`, `noOps`) and a `reviewVersion`, which is `null` when the file has any error. The confirmation sends the same file with that `reviewVersion`. It checks the grant again, and saves the whole file in one transaction only if the file and the saved data it touches still give the same version. Otherwise it answers 409 `impact_changed`. Not confirming is the API's **Cancel**: nothing is saved.

**What is timed.** One edit: a keyboard move of one tile to another term row (UC-05 A1: Space lifts the focused tile, the arrows pick a row, Enter drops). Before each Space, focus `[data-test="tile-<code>"]`: Undo does not put the focus back, and a blur cancels a lift. After the arrows, wait until the target row has lost the class `checking`, so the lift's drop preview (`POST /api/plans/{id}/issues/drops`) has answered, before Enter: Enter only aborts that request in the browser, and the server could still be computing it during the timed save. The clock starts at the Enter `keydown`, which a capture listener on `window` stamps with `performance.now()`. It stops at the first animation frame where all of these hold: the moved tile is in its target row (`[data-test="term-<year>-<number>"]` holds `[data-test="tile-<code>"]`); `[data-test="issues-panel"]` has `aria-busy="false"`; `[data-test="issue-counts"]` has no `stale` class, so the report on screen is the one for the board on screen; and the edit's expected result (table below) is drawn. The script reads the drawn issues themselves, not a flag the app sets. A keyboard move is used instead of a mouse drag because its start is one exact event, and a scripted drag's own motion would be timed with it.
