## Findings for triage

1. **USER-01k, test-case wording (Dũng):** UC-01 A7 is built as "other programs listed, not selectable" plus "Làm sau"; the case's "choose My program isn't listed" cannot be done.
2. **USER-01k, behaviour (Lâm):** an unfinished account opening the dashboard is redirected to onboarding; the case expects the dashboard to ask. Code does it on purpose (`router.ts:83`). Decide which is right.
3. **USER-01w (Lâm):** after deleting the account the app shows the home page with a toast, not the sign-in screen (`DeleteAccountDialog.vue:49`). Decide which is right.
4. **GUIDE-01 (Dũng, Lâm):** no guide on production; #112 (G01, G07) needs a reviewer. With G02 and G06 still draft, GUIDE-01b, c, d, e cannot fully pass even after #112. **Update:** #112 merged and deployed; the cases were run again on G01 and G07 (above). G02 and G06 wait for the next registration and tuition periods.
5. **A11Y-01b, focus after actions:** after removing a placed course, focus goes to the course search box scrolled out of view (`PlanEditorView.vue` `remove()` uses `preventScroll`). After adding a course, saving Settings, exporting, and closing the revoke-session dialog, focus falls to `<body>`; after the revoke it restarts at the top of the page.
6. **A11Y-01b, skip link:** on sign-up, sign-in and onboarding, `#main` wraps the top bar, so the skip link skips nothing; there is a `<main>` inside `<main>`. On sidebar pages it works.
7. **A11Y-01b, usability note:** reaching the planner board from the top takes about 90 Tabs (every tray course and slot first).
8. **A11Y-01d:** "What-if" untranslated in Vietnamese.
9. **A11Y-01e:** contrast as above; `scrollable-region-focusable` on the audit at 360 px.
10. **A11Y-01f:** text-field borders 1.42:1 light (`#cdd2da` on `#f6f7f9`) and 1.78:1 dark (`#363d4e` on `#0c0e13`), need 3:1. Dark placeholder 3.89:1 (Chrome default `#757575` on `#14171f`), need 4.5:1. Light hint "Không cần tên thật…" 4.45:1 (`#6b7383` on `#f6f7f9`). Progress bar against its track: dark blue 2.57 and purple 2.55, light green 2.85, need 3:1 (above 3:1 against the card; value also written). Passed: body, secondary and sidebar text; status labels; group glyphs 5.1–9.0; focus outline 5.48 light, 5.81 dark; teal panel 5.14.
11. **Observation:** the custom select keeps its list open after an option is clicked with the mouse (keyboard Enter closes it).
12. **Not an app defect:** in the tester's Chrome, Esc never closed dialogs because the Claude in Chrome extension cancels the Esc key (`defaultPrevented` before the dialog sees it). In a clean browser Esc works. Run keyboard checks without that extension.
13. **test-plan.md §5 (Thắng):** row `TC-B1-PLAN-01` still says "Live validation and drag-and-drop remain B2"; the B1 build has the drag preview (#103 merge-danger note).
14. **GUIDE-01e, defect (Dũng retests):** in a guide step that has a link, the link was a third item of the step's two-column grid and fell into the 34 px number column, one letter per line (G01 step 3 on production). Fixed in PR #121 with a browser test; retest G01 after it deploys.
15. **GUIDE-01, content for version 2 (Dũng):** G07's re-mark note quotes the school's re-mark notice but its source line says "kinh nghiệm của nhóm OmniCourse"; guides plan §2 allows only a regulation clause or team experience as a source.
